原始页：`data/pages/真实亦是谎言__1d60ad4965.json`。以下源行号指解码后的 Wikitext，JSON 行号指当前同名角色任务文件。

```text
*幕府通告：恒常乐土，雷光昭昭。此番吉庆之际：
*幕府通告：天领奉行家主名代，九条镰治大人。

*幕府通告：已决定于近日成婚并举办婚礼。特此通告。
```

4 条均以 `说话者="幕府通告"`、`类型="character"` 导出，对应 JSON 指针 `/对话/84` 至 `/对话/87`，说话者在 JSON 第 539、545、551、557 行。


紧邻的 147–152 行另有“额外对话（在楼梯转角的公告板前）”，其中小百合和真理正在讨论婚讯。这是需要保留的真人发言。不能因为标题含“公告板”就将所有邻近文本一律改成旁白。

### 判断与定位

六段公告的原文字面均能从当前“说话者 + 冒号 + 内容”完整重建，因此不计为新漏文。独立恢复单元仍将它们标为 `type="dialogue"`、`speaker_status="resolved"`，并非已保留未知角色的诊断状态。

`get_genshin_wiki/recovery/extract.py:14` 的折叠文档规则和第 15–19 行的行级阅读/文档标签规则，尚未覆盖这些公告表达；449 行起继续把冒号前内容当作角色。597 行的折叠文档判断也不能正确区分这两个公告与其附近的真人对白。

建议后续依据明确的公告/文档上下文识别书面内容，保留原标签和来源；同时用本页紧邻真人对白做反例，防止只扩展标题关键词后误伤正常对白。当前证据支持上述 6 条误分类，不用于推算全库影响数量。
