# 剧情旁白与非角色文本修正

日期：2026-11-04。工作分支：`develop/v2.3`。修改未提交、未推送。

本轮执行聊天“验证聊天对话串中的修改”最后两轮方案。修正范围是剧情中的旁白、文档和交互提示，未改角色、武器、材料等非剧情实体解析器。

## 保存方式

旧业务 JSON 保持原字段。魔神任务和角色任务的非角色文本使用空说话者和 `类型=narration`；活动任务仍使用 `类型=旁白`。公告的标签和正文完整保留，不把“幕府通告”等标签当作人物。

恢复 API 与新 JSONL 增加：

| 字段/值 | 含义 |
|---|---|
| `narration_kind=narrative` | 明确标为旁白的文本、剧情中的任务描述 |
| `narration_kind=document` | 有文档语境或明确标签证据的书面内容 |
| `narration_kind=interface` | 阅读等动作提示 |
| `narration_kind=unknown` | 不能确认性质的文本，保留并记录诊断 |
| `document_id` / `document_title` | 关联同一文档的连续段落，仅文档单元具有 |
| `narration_label_source` | 原文显式“旁白”标签的位置，旁白单元不再具有角色身份 |

文档分组沿用页面、场景、分支和局部作用域；真人发言会中断连续分组。嵌套展示折叠继承明确文档语境；独立文档和选项分支分别分组。公告板前的真人发言仍为 dialogue。

分类不替代出处判断：未知文本的 `source_kind=unknown`，双冒号编者文本仍为 `wiki_editorial`，不统一认定为游戏原句。附着黑幕候选注释单独记录，完全隐藏的正文保留并诊断。沿用现有 annotation_status=unresolved，未把全部黑幕认证为编者说明。
