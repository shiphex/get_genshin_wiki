# 实体版本与离线解析更新（2026-11-04）

## 实现与数据口径

17 类实体根对象统一包含 `所属版本` 字符串。角色普通/精简格式、魔神任务、单页解析、批处理及完整恢复均支持。多版本保留来源顺序并用顿号连接，数字与“月之…”不互转；缺失、占位或冲突为空。部件、分卷、对白、奖励和树节点不新增版本。

共享提取器只读取主体元数据。HTML 布局标签中的主体可读取；嵌套实体、食谱、正文条件、页面修改日期及技术示例不作为来源。原文回退要求主体语法确有未闭合结构、参数行明确、候选可定位，并排除代码/示例标签。真实材料与武器原页 fixture 及 SHA-256 保存在 `tests/fixtures/versions/`。
