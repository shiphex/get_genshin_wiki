# V2.3.1

基于 release/V2.3.0 和指定 0605 冻结数据包进行离线修复。

- ruby 保留基底文字，忽略 rt 注音与 rp 回退括号，避免未知标记导致整句漏失。
- 共享剧情解析支持半角/全角冒号，包括 HTML 包裹与换行边界；文档、引用、阅读动作、旁白和玩家选项保留原有分类。
- 新增原页回归及独立快照重建工具，输出原文证据、业务与恢复层差异、候选筛查和 Pointer 对照。
- 项目版本与锁文件更新为 2.3.1；第三方依赖不变。业务 JSON 不新增字段，受影响数组的 Pointer 应从新包重新定位。

## 复现

```powershell
python tools/rebuild_parser_snapshot.py --source-zip <genshin_wiki_data_20260605_261104.zip> --output-root <不存在的新目录>
```

原包 SHA-256 必须为
`13b71711bde300d5f1833e64d29381a1c32cb7e70da106d76bf1126f9c862ed1`。
旧解析器取自本地 release/V2.3.0，不访问网络。

仅新目录中的 snapshot/ 进入数据 ZIP，input/、旧代码和中间审计目录为复现证据。
失败暂存若已有完整验证的旧基线，可显式使用 `--finish-staged`：先复核基线与输入哈希，再重解析全部当前业务和 recovery，保留失败输出；不覆盖完成后的快照。
完整验证、候选分类和交付哈希见同包 reports/parser-v2.3.1/ 及包外报告。
旧原包与现有 data 不覆盖，不涉及 RAG 修改或线上发布。
