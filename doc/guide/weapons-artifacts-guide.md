# 武器与圣遗物套装数据获取指南

本指南说明如何使用本项目获取原神武器与圣遗物套装数据。

## 数据模型

### 武器 (WeaponRecord)

| 字段 | 类型 | 说明 |
|------|------|------|
| 名称 | str | 武器名称 |
| 类型 | str | 武器类型（单手剑、双手剑、长柄武器、弓、法器） |
| 介绍 | str | 武器介绍 |
| 突破武器材料序列 | list[str] | 突破武器材料 |
| 突破高级材料序列 | list[str] | 突破高级材料 |
| 突破普通材料序列 | list[str] | 突破普通材料 |
| 获取途径 | str | 获取方式（祈愿/限定祈愿/活动/图纸兑换等） |
| 锻造材料 | str | 锻造所需材料，不可锻造为"不可锻造获取" |
| 精炼材料 | str | 精炼所需材料，不可精炼为"不可使用材料精炼" |
| 故事 | str | 武器背景故事 |

### 圣遗物套装 (ArtifactSetRecord)

| 字段 | 类型 | 说明 |
|------|------|------|
| 名称 | str | 套装名称 |
| 获取方式 | str | 获取方式（如"月童的库藏：圣库"或"击杀首领或周本BOSS"） |
| 时之沙/死之羽/理之冠/生之花/空之杯 | 各部件含：名称、描述、故事 | 套装五个部件 |

## 存储位置

- 原始页面数据：`data/pages/`
- 武器解析结果：`data/parsed/artifacts/`
- 圣遗物套装解析结果：`data/parsed/weapons/`

## 使用方法

### 1. 爬取数据

```bash
# 爬取武器分类（15个）
python -m get_genshin_wiki.cli crawl category-pages 武器 --page-limit 15

# 爬取圣遗物套装分类（15个）
python -m get_genshin_wiki.cli crawl category-pages 圣遗物套装 --page-limit 15
```

### 2. 解析数据

```bash
# 解析特定武器页面
python -m get_genshin_wiki.cli parse weapon "霜结的誓金枝"

# 解析特定圣遗物套装页面
python -m get_genshin_wiki.cli parse artifact "风起之日"

# 批量解析武器（需自行编写脚本遍历 pages 目录）
```

### 3. 存储结构

文件命名格式：`{名称}__{hash}.json`

解析输出示例（武器）：

## 获取途径解析规则

### 武器获取途径
- `[[祈愿]]` 或 `[[限定祈愿]]` → "祈愿" 或 "限定祈愿"
- 含"锻造"字样 → "图纸兑换" 或 "锻造"
- `[[活动名称]]：任务名称：获取方式` → "活动名称：获取方式"

### 圣遗物套装获取方式
- `获取途径=[[地点]]：...：名称` → "地点：名称"
- `获取方式={{圣遗物套装/获取途径|类型|描述}}` → 提取描述部分

## 注意事项

1. HTML注释 `<!-- -->` 会在解析时自动去除
2. `<br>` 标签会替换为换行符 `\n`
3. 多个获取方式用"、"分隔
