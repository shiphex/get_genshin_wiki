# 活动任务数据获取指南

本指南说明如何使用本项目获取原神活动任务数据。

```bash
cd E:\Workplace\Learn_project\get_genshin_wiki-event-quests
.\.venv\Scripts\Activate.ps1
```

依赖安装：

```bash
pip install mwparserfromhell requests
```

## 数据模型

### EventQuestRecord

| 字段 | 类型 | 说明 |
|------|------|------|
| 任务名称 | str | 最小子任务名称 |
| 任务地区 | str | 任务所属地区（蒙德/璃月/稻妻等） |
| 任务类型 | str | 任务类型（活动事件/传说任务等） |
| 所属版本 | str | 所属游戏版本号 |
| 所属任务 | str | 所属活动的名称 |
| 所属任务描述 | str | 所属活动的描述文本 |
| 相关角色 | str | 出场角色，以"、"分隔 |
| 前置任务 | str | 前置任务名称 |
| 后续任务 | str | 后续任务名称 |
| 活动列表 | list[str] | 活动剧情任务列表 |
| 活动名称 | str | 活动名称 |
| 活动期间 | str | 活动起止时间 |
| 任务描述 | str | 当前任务的描述 |
| 任务列表 | list[str] | 任务流程步骤标题 |
| 剧情对话 | list[EventQuestStepRecord] | 分步骤的剧情对话 |

### EventQuestStepRecord

| 字段 | 类型 | 说明 |
|------|------|------|
| 任务流程 | str | 流程步骤标题 |
| 对话 | list[EventQuestDialogueEntry] | 该步骤下的对话列表 |

### EventQuestDialogueEntry

| 字段 | 类型 | 说明 |
|------|------|------|
| 类型 | str | 对话类型（角色/NPC / 旅行者 / 选项 / 旁白） |
| 说话者 | str | 说话者名称（仅角色/NPC 和旅行者类型） |
| 内容 | str | 对话文本内容 |
| 选项 | list[str] | 玩家可选回复列表（仅选项类型） |

## 使用方法

### 1. 爬取数据

```bash
# 批量抓取活动任务（自动发现分类、抓取页面及关联活动页）
python -m get_genshin_wiki.cli crawl event-quests

# 限制抓取数量（只抓前 50 个）
python -m get_genshin_wiki.cli crawl event-quests --page-limit 50

# 不持久化到本地（仅输出到 stdout）
python -m get_genshin_wiki.cli crawl event-quests --page-limit 10 --no-persist
```

爬取命令会自动：
1. 探测 Wiki 分类（`活动事件`）
2. 获取分类下所有成员页面
3. 逐页抓取并解析
4. 识别关联活动页面并同步抓取

### 2. 解析数据

```bash
# 解析单个活动任务页面
python -m get_genshin_wiki.cli parse event-quest "猫茸茸城堡的大大危机"

# 仅查看解析结果，不保存
python -m get_genshin_wiki.cli parse event-quest "百人一揆·黄金旋风" --no-persist
```

解析命令会自动：
1. 读取本地存储的页面 payload
2. 尝试加载关联活动页 payload
3. 从活动页提取 `所属任务描述`
4. 解析页面模板、章节、对话

### 3. 批量重解析

```bash
# 对已抓取的页面进行批量离线重解析
python tools/reparse_and_store.py --entity event-quests --limit 50
```

## 存储位置

- 原始页面数据：`data/pages/`
- 活动任务解析结果：`data/parsed/event-quests/`
- 分类信息：`data/categories/`
- 验证报告：`data/validation_event_quest_50/`

文件命名格式：`{名称}__{hash}.json`

## 对话类型说明

| 类型 | 说明 | 解析规则 |
|------|------|---------|
| `角色/NPC` | 非旅行者的角色对白 | 说话者名称不为"旅行者" |
| `旅行者` | 旅行者的对白/选项选择 | 说话者为"旅行者" |
| `选项` | 玩家可选择的多个分支回复 | 来自 `{{剧情选项}}` 模板 |
| `旁白` | 无说话者的场景叙述/动作描写 | 行末无 `：` 分隔符 |

## 数据结构层级

```
活动任务列表页（活动事件）
  └─ 所属活动任务名称
      └─ 所属活动任务的活动描述
        ├─ 任务1
        │   ├─ 任务描述
        │   └─ 对话
        │       ├─ 角色/NPC/派蒙 对白
        │       ├─ 旅行者 对白
        │       ├─ 选项（玩家选择分支）
        │       └─ 旁白/场景叙述
        ├─ 任务2
        │   ├─ 任务描述
        │   └─ 对话
        └─ 任务n ...
```

## 注意事项

1. 遵循 `robots.txt` 规则
2. 请求有频率限制，避免短时间内大量请求
3. 对话内容中的 `<br>` 标签会替换为换行符 `\n`
4. Wiki 分类实际使用 `活动事件`（非 `活动任务`）
5. `所属任务描述` 从所属活动页面的 `活动描述` 字段自动提取
6. 部分页面因源站点数据不完整，`活动列表` 或 `剧情对话` 可能为空
7. 支持多种 wikitext 章节格式：`任务剧情` / `剧情` / `任务剧情·分支N`
8. 奖励数据不在提取范围内
