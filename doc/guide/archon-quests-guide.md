# 魔神任务数据获取指南

本指南说明如何使用本项目获取原神魔神任务剧情数据。

## 环境准备

```bash
# 激活虚拟环境
# 从仓库根目录执行；环境准备见统一操作指南
.\.venv\Scripts\Activate.ps1
```

## 获取步骤

### 方式一：批量抓取与解析（推荐）

一次性完成列表页抓取、任务展开、解析、索引生成：

```bash
# 批量抓取并解析全部魔神任务（约需 2-5 分钟）
python tools/batch_archon_quests.py

# 生成索引文件（含前置/后续任务关系）
python tools/generate_archon_quest_index.py
```

可选参数：

| 参数 | 说明 | 默认值 |
|------|------|--------|
| `--data-root` | 数据存储根目录 | `data/` |
| `--output` | 输出 JSON 路径 | `data/archon_quests.json` |
| `--list-title` | 列表页标题 | 魔神任务 |
| `--resume` | 断点续传，跳过已有记录 | 关闭 |

### 方式二：单任务解析

```bash
# 解析单个魔神任务页面（需先抓取页面原始数据）
python main.py crawl page "鸟瞰风物"
python main.py parse archon-quest "鸟瞰风物"

# 仅查看解析结果，不保存
python main.py parse archon-quest "捕风的异乡人" --no-persist
```

### 对话字段

| 字段 | 说明 | 示例 |
|------|------|------|
| `说话者` | 说话角色名 | 派蒙 / 旅行者 / 凯瑟琳 |
| `内容` | 对话文本 | 那就是「七天神像」了。 |
| `类型` | 对话类型 | character / traveler / option / narration |
| `所属任务流程` | 对话归属的流程节点 | 到派蒙附近 / 与凯瑟琳对话 |

### 对话类型说明

| 类型 | 说明 |
|------|------|
| `character` | 角色/NPC/派蒙 对白 |
| `traveler` | 旅行者（空/荧）对白 |
| `option` | 玩家可选回复分支 |
| `narration` | 旁白/场景叙述/动作描写 |

### 折叠剧情与旧快照重解析

剧情区域中的 `{{折叠|标题=...|内容=...}}`、第二位置参数及嵌套折叠均通过共享恢复层读取，
不依赖折叠标题。`<br>`、`<br/>`、`<br />`、大小写和带属性的写法均可作为对话候选边界；
有显式说话者才生成角色台词，未标记且无明确内容范围的片段保留为旁白并诊断。
同名角色连续发言不会按文本去重，折叠前后保持原文顺序。

原始页面已存在时，可离线重新生成单页业务 JSON：

```powershell
python main.py parse archon-quest "尾声的尾声"
```

该命令更新单页，不更新 `archon_quests.json` 汇总。完整冻结快照重解析需同时重建单页和汇总；
已有 JSON 不会因代码升级自动更新，旧结果不能仅靠 `--resume` 修复。
需要原文位置与未支持内容清单时，使用 `WikiTextParser.recover_page(payload)`，
或使用 [冻结快照恢复入口](snapshot_recovery_guide.md) 写独立输出目录。
具体 0605 验收及 17 行对照见 [修复报告](../reports/fold_dialogue_2026-10-30.md)。

第一轮报告已被独立抽样否决，当前已知缺陷修复见 [语义补修报告](../reports/fold_dialogue_audit_fix.md)。
台词中的附着黑幕单独保留为恢复 annotation；例如旅行者台词为 `温迪——！`，
`哑巴开口` 留在注释记录中。文档明细按旁白保存，不将账目标签视为角色姓名。

### 索引文件

`generate_archon_quest_index.py` 生成的索引每条记录包含：

| 字段 | 说明 |
|------|------|
| `title` | 任务名称 |
| `chapter` | 章节编号 |
| `chapter_name` | 章节名称 |
| `act` | 幕编号 |
| `act_name` | 幕名称 |
| `series_title` | 系列任务标题 |
| `前置任务名称` | 前置任务名称 |
| `后续任务名称` | 后续任务名称 |

## 存储位置

- 原始页面 JSON：`data/archon_quests/pages/`
- 分类列表：`data/archon_quests/categories/`
- 分类成员：`data/archon_quests/category_members/`
- 解析结果：`data/archon_quests/parsed/archon-quests/`
- 索引文件：`data/archon_quests/parsed/archon-quest-index/`
- 输出汇总：`data/archon_quests/archon_quests_output.json`
- 独立索引：`data/archon_quests/archon_quest_index.json`

## 注意事项

- 遵循 `robots.txt` 规则，避免短时间内大量并发请求
- Wiki 页面分为 `{{系列任务}}`（章节概要）和 `{{任务}}`（具体任务含对话），工具会自动展开系列页面到子任务
- `{{选项}}` 模板中的玩家分支对话支持解析
- 空月之歌章节无数字编号，章节字段直接填入「空月之歌」
- 对话中的 `<br>` 会被替换为 `\n`
- 奖励数据不提取

阅读动作、文档物件标签和整句配对引用按行保留为 narration，标签不再当作说话者。
混合折叠内的真实角色发言仍单独识别；不完整说话者引号保留并诊断，
第二轮复验见 [文档/UI 补修报告](../reports/document_ui_fix_2026-11-04.md)。

旁白的说话者统一为空；恢复层 `narration_kind` 区分叙述、文档、交互提示和未知，
文档段落用 `document_id` 关联。公告板中的明确通告行按文档保存完整标签，
同处真实角色对白继续正常记录。细分和未知诊断见 [恢复指南](snapshot_recovery_guide.md)。
