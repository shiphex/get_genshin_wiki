## 根因及当前架构

1. `client.fetch_page_payload()` 读取 MediaWiki revisions 主插槽原始 Wikitext，
   `crawler.crawl_page()` 通过 JsonFileStore 写入 `data/pages/`。
   原始《尾声的尾声》确有两个过场折叠及额外对话，无抓取丢失。
2. 模板识别使用 mwparserfromhell 的递归 AST 和参数提取，能识别多行、嵌套模板。
   但旧魔神任务对白路径 `_extract_archon_dialogues()` 只展开选项模板，随后
   `_normalize_plain_text()` 的 `strip_code()` 删除完整折叠模板及其内容。
   普通 `*温迪：台词` 是模板外文本，因此能保留。这是内容提取阶段丢失，
   不是 RAG 问题，也不是缺少 `<br>` 后的源码换行。
3. 在同一 0605 原页上重跑旧私有路径得到 117 条，吻合快照的 117 条旧产物；
   夺心 17 行均缺失。v2.2 已将三个任务入口接入 `recover_page()`，
   按 AST 原始位置递归处理折叠，再用 legacy adapter 导出。
   因此本次修改前的当前代码已经能读取原页夺心 17 行、导出 157 条。
   不能将该已有能力宣称为本次新实现，也不能仅修代码而继续发布旧 JSON。
4. 当前恢复层仍只在顶层 Text 的源码换行处分行，`<br>` 独立分隔的多个说话者
   会混进第一位角色的内容。内联 HTML 包住整段对白时，冒号也可能被当作纯显示内容。
5. 兼容投影原先无条件过滤具有子场景的章节前导场景，导致已提取对白二次丢失。
   普通折叠若处于已识别剧情区外，原先缺少来源范围诊断，也不能直接猜测其中冒号为角色标记。

## 修改范围

- `get_genshin_wiki/recovery/extract.py`：按 AST 的 HTML 换行处理候选片段；
  显式角色标记独立分离；列表项、人物对话模板及台词内显示标签限定续行范围；
  无范围依据的片段保留为旁白并诊断；逻辑行起点进入包裹完整对白的 HTML。
  剧情区外折叠保留 description 与诊断；任务描述及其未知参数分别保留、诊断。
- `get_genshin_wiki/recovery/legacy.py`：仅过滤无有效业务文本的章节包装场景，
  保留子章节前的有效对白和旁白；保持原有字段映射。
- `tests/test_fold_dialogue.py` 与 `tests/fixtures/fold_dialogue/`：新增完整原始页面、
  文件哈希来源及真实页面回归；补充换行、嵌套、同角色重复、HTML、实体、续行、
  非剧情内容、前导场景、未知节点诊断测试。
- 同步架构、统一指南、魔神任务指南及 CLAUDE.md。未修改下游仓库和抓取架构。

```wikitext
「女士」：给蒙德添了那么多麻烦…<br>
温迪：你说的不是仓鼠，是老鼠——<br>
```

对应导出：

```json
[
  {"说话者":"「女士」","内容":"给蒙德添了那么多麻烦…","类型":"character","所属任务流程":"将天空之琴交给芭芭拉"},
  {"说话者":"温迪","内容":"你说的不是仓鼠，是老鼠——","类型":"character","所属任务流程":"将天空之琴交给芭芭拉"},
  {"说话者":"「女士」","内容":"现在没你说话的份，无礼的吟游诗人。","类型":"character","所属任务流程":"将天空之琴交给芭芭拉"}
]
```

完整 17 行逐行对照（含原始 Wikitext、业务 JSON 与来源位置）写入
`data/reports/taking-heart-17-lines.json`。其固定预期也在新增测试中逐条列出。
`「女士」` 保留引号，连续发言和重复文本保持顺序，不按台词去重。

原文旅行者一行是 `旅行者：温迪——！{{黑幕|哑巴开口}}<br>`。
沿用既有黑幕显示规则后内容为 `温迪——！哑巴开口`，类型为 `traveler`，
说话者仍为 `旅行者`。本次没有把原文中的编辑注释删除或自行改写成游戏台词；
编辑注释与游戏原句的进一步分离是后续独立的数据规则。

## 兼容性与后续排查

魔神任务 / 角色任务继续使用 `说话者`、`内容`、`类型`、`所属任务流程`，
活动任务继续使用已有步骤与对话结构。本次不增加业务字段、不更名角色，
诊断只通过原有恢复 API 或独立报告读取。旧 0605 角色任务迁移到当前已有的
`source_title`、`page_id` 规则，下游应按源身份区分同名页面。
对话数量和含有效前导剧情的流程数量可能增加，这是恢复缺失文本的预期结果。

仍需排查未知模板、非标准折叠参数、页外转引 / 缺少缓存依赖、复杂分支与
编辑注释。诊断数量不等于缺失台词数量：无标记换行片段已经保留为旁白；
未支持模板的原始片段保留在 issues 中，不推断未明确标注的角色或补写台词。
