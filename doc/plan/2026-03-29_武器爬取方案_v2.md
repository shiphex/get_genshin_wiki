> 本文档版本：v2.0（2026-03-29）
> 更新说明：v2.0 基于实际实现经验全面修订，整合了操作指南和完善了数据字段说明

## 1. 概述

### 1.1 数据目标

爬取哔哩哔哩原神 Wiki 的武器数据，用于 RAG/Agent 训练数据集。

**目标页面：**
- 武器图鉴列表：https://wiki.biligame.com/ys/%E6%AD%A6%E5%99%A8%E5%9B%BE%E9%89%B4
- 每件武器的详情页：如 https://wiki.biligame.com/ys/狼的武功歌

### 1.2 爬取策略

采用 **HTML 解析** 方式，通过 MediaWiki API 的 `action=parse` 获取渲染后的 HTML，再用 BeautifulSoup 解析。

**原因：** 武器详情页的 HTML 结构包含丰富的样式信息（如星级、属性颜色），纯 wikitext 无法直接获取这些格式化数据。

## 4. 核心解析逻辑

### 4.1 武器发现

**问题：** 武器图鉴页面包含大量非武器链接（角色、任务、导航等）

**解决方案：** 只从 `<div class="visible-xs">` 元素中提取链接

```python
visible_xs_divs = soup.find_all("div", class_="visible-xs")
for vis_div in visible_xs_divs:
    for a in vis_div.find_all("a", href=True):
        # 提取武器链接
```

**过滤规则：**
- 排除 `/ys/文件:` 前缀（文件页面）
- 排除包含 `action=` 的链接
- 排除导航页面（角色一览、书籍一览等）

### 4.2 武器信息解析

#### 名称和稀有度

```html
<span class="mw-headline" id="狼的武功歌"><b>狼的武功歌</b></span>
<div style="color:#FFAF52; font-size:x-large;">★★★★★</div>
```
- 名称：从 `mw-headline` 的 `id` 属性获取
- 稀有度：统计 ★ 字符数量

#### 性能描述文本

```html
<p>攻击力 46-608 <span class="visible-xs-inline"><br /></span><span class="hidden-xs">///</span> 暴击率 7.2%-33.1%</p>
```
- 移除 `<span class="visible-xs-inline">` 和 `<span class="hidden-xs">` 及其内容
- 合并结果：`攻击力 46-608 /// 暴击率 7.2%-33.1%`

#### 武器技能

```html
<div class="card-title2" style="width:100%; margin-top:16px;">武器技能 - 不灭的骑士道</div>
```
- 提取 `武器技能 - ` 后面的技能名称

#### 技能描述

```html
<div style="width:100%; margin-top:8px;">攻击速度提升10%...</div>
```

#### 突破材料（card-title3/card-content3 模式）

```html
<div class="card-title3">突破材料</div>
<div class="card-content3">...</div>
```

**注意：** 突破材料按等级分组，每个等级的材料按顺序排列

#### 其他字段（card-title3/card-content3 模式）

```html
<div style="margin:16px 0 0 0">
    <div class="card-title3">武器介绍</div>
    <div class="card-content3">传说中，是继承了「北风」之名的瑞文伍德...</div>
</div>
```

支持字段：
- 武器介绍、获取途径、实装版本、武器类型、武器TAG

#### 故事（`<br />` 换行处理）

```html
<div id="mc_collapse-1" class="panel-body panel-collapse collapse">
    在诗与酒的国度，自古便流传着诸多歌咏骑士武功的篇章。<br />
    <p>在所有华美的诗篇当中，有关「狼」的故事往往最受欢迎。<br /><br />
    ...
</div>
```

**换行规则：**
- 单个 `<br />` → `\n`
- 连续 `<br /><br />` → `\n\n`
- 依次类推

**实现：**
```python
def replace_consecutive_brs(match):
    count = len(re.findall(r'<br\s*/?>', match.group(0)))
    return '\n' * count

html_content = re.sub(r'(<br\s*/?>)+', replace_consecutive_brs, html_content)
```

## 6. 技术细节

### 6.1 请求配置

- 间隔：3 秒（`configs/config.yaml` 中 `request_interval`）
- 超时：30 秒
- 重试：最多 3 次，指数退避

### 6.2 错误处理

- 捕获具体异常类型，不使用裸 `except:`
- 失败武器记录到 `failed_arms.txt`
- 支持断点续爬（读取已保存/失败记录后跳过）

### 6.3 日志

使用标准库 `logging`，格式：`%(asctime)s - %(name)s - %(levelname)s - %(message)s`

### 6.4 数据输出

- JSONL：每行一条 JSON，便于流式处理
- JSON：JSON 数组，便于阅读调试
