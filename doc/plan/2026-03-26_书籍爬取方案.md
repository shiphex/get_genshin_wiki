# 书籍爬取方案

## 目标

从[哔哩哔哩原神 Wiki](https://wiki.biligame.com/ys/) 爬取游戏内书籍数据，包括：
- 书籍基本信息（名称、卷数、稀有度、体裁、国家、実装版本、图鉴、相关角色）
- 每卷的标题和文本内容
- 每卷的获取方式

## 爬取流程

### 第一步：获取书籍列表

**目标页面**：[书籍一览](https://wiki.biligame.com/ys/%E4%B9%A6%E7%B1%8D%E4%B8%80%E8%A7%88)

**方法**：通过 MediaWiki API 获取页面 HTML 内容

```python
# 使用 MediaWikiClient 获取页面渲染后的 HTML
client.get_page_html("书籍一览")
```

**关键点**：
1. 从页面 HTML 中提取所有书籍链接
2. 链接格式通常为 `/ys/<书籍名>` 或 `/ys/终北祷歌集` 等
3. 需要识别并去重

### 第二步：获取每本书的详情页

**方法**：对每本书的详情页获取 HTML 内容

```python
client.get_page_html("终北祷歌集")
```

**从 HTML 中提取信息**：

1. **书籍基本信息**（Infobox）
   - 需要解析页面中的 Infobox 模板
   - 使用 `WikitextParser` 解析 wikitext 中的模板

2. **每卷标题**
   - HTML 结构：`<span class="mw-headline" id="卷名">卷名</span>`
   - 使用 BeautifulSoup 提取所有 `span.mw-headline`

3. **每卷文本内容**
   - 位于每卷标题 `h2` 标签后的段落
   - 需收集从当前 `h2` 到下一个 `h2` 之间的所有 `<p>` 标签内容
   - 可能有多个段落

4. **获取方式**
   - 通常在每卷的最后一个段落或特定章节中
   - 需确定具体的 HTML 结构

### 第三步：数据解析策略

```
对于每本书详情页 HTML：
1. 解析 Infobox（书籍基本信息）
2. 定位所有 <h2> 标签（每卷的标题）
3. 对每卷：
   - 提取 <span class="mw-headline"> 中的 id 作为卷名
   - 收集该 <h2> 到下一个 <h2> 之间的所有 <p> 文本
   - 查找"获取方式"相关段落
4. 组装数据结构
```

### 第四步：数据存储

**存储位置**：`storage/book/`

**文件结构**：
```
storage/
└── book/
    ├── raw/           # 原始 HTML/Wikitext
    ├── cleaned/      # 清洗后的文本
    └── books.jsonl    # 结构化数据
```

**JSONL 记录格式**：
```json
{
  "title": "终北祷歌集",
  "url": "https://wiki.biligame.com/ys/终北祷歌集",

  "volumes": [
    {
      "title": "第一卷",

    }

```

## 技术要点

### 1. 不遗漏数据的关键

- **书籍列表**：先通过 MediaWiki API 获取完整列表页面，再提取所有链接
- **卷标题**：使用 `span.mw-headline` 选择器，确保找到所有卷
- **卷内容**：使用 `h2` 标签作为分卷边界，正确划分每卷内容
- **获取方式**：需要分析页面结构确定获取方式的位置

### 2. 异常处理

- 页面不存在：`PageError`
- 解析失败：记录错误，继续处理下一本书
- 某卷内容为空：记录警告，保留空值

### 3. 进度保存

- 定期保存已完成的书籍列表
- 支持中断后恢复
