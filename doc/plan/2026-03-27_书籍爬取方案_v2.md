## 1. 概述

### 1.1 实现状态

已全部实现，书籍数据已爬取完成（102 本）。

### 1.2 数据目标

- 书籍列表（书籍一览页面）
- 每本书的详情页（终北祷歌集等）
- 每卷的标题和文本内容
- 书籍相关信息（名称、卷数、稀有度、体裁、国家、実装版本、图鉴、相关角色、获取方式）

### 1.3 爬取策略

采用 **HTML 解析** 方式，通过 MediaWiki API 的 `action=parse` 获取渲染后的 HTML，再用 BeautifulSoup 解析。

## 3. 核心解析逻辑

### 3.1 书籍发现

从"书籍一览"页面 HTML 中提取所有书籍链接：

```python
html = client.get_page_html("书籍一览")
links = parser.extract_book_links(html)
```

链接过滤规则（跳过非书籍页面）：
- 排除 `/ys/文件:` 前缀（文件页面）
- 排除包含 `action=` 的链接
- 排除导航页面（角色一览、武器一览等）
- 排除"创建新页面"、"任务道具一览"
- 链接文本去重

### 3.2 书籍信息解析（Infobox）

从 `table.wikitable.boxright` 解析：

| Infobox 字段 | book.info 字段 |
|-------------|----------------|
| 名称/名称/外文名称 | name |
| 卷数 | volumes_count |
| 稀有度 | rarity（含图片 alt 提取） |
| 体裁/类型 | genre |
| 国家 | country |
| 実装版本/实装版本 | version |
| 图鉴/画廊 | gallery |
| 相关角色/角色 | related_characters（去重） |

获取方式在 Infobox 中按卷名分隔存储，解析后汇总为：
`"卷名1: 获取方式1; 卷名2: 获取方式2; ..."`

### 3.3 卷内容解析

每卷标题：`<span class="mw-headline" id="卷名">卷名</span>`

解析方法：
- 遍历所有 `span.mw-headline`
- 跳过目录、导航、参考资料等非内容标题
- 收集该标题到下一 h2 之间的所有 `<p>` 标签

换行处理：
- `<br />` → `\n`（诗歌内部换行）
- `<p>` → 段落分隔

## 4. 数据流程

```
1. crawl_book_list()        # 获取书籍一览页，提取链接列表
2. 过滤已保存/已失败的书籍  # 断点续爬
3. 对每本书：
   ├── client.get_page_html(title)  # 获取详情页 HTML
   ├── parser.parse_book_page()     # 解析 HTML
   ├── storage.save_book()          # 保存
   │   ├── books.jsonl             # JSONL 结构化数据
   │   └── cleaned/*.txt           # 清洗后纯文本
   └── sleep(request_interval)      # 请求间隔
```

## 6. 技术细节

### 6.1 请求配置

- 间隔：3 秒（`configs/config.yaml` 中 `request_interval`）
- 超时：30 秒
- 重试：最多 3 次，指数退避

### 6.2 错误处理

- 捕获具体异常类型，不使用裸 `except:`
- 失败书籍记录到 `failed_books.txt`
- 支持断点续爬（读取已保存/失败记录后跳过）

### 6.3 日志

使用标准库 `logging`，格式：`%(asctime)s - %(name)s - %(levelname)s - %(message)s`

## 7. 扩展说明

### 7.1 后续扩展（角色/任务/剧情）

参考本方案的结构：

1. 在 `src/parser/` 下新增 `xxx_parser.py`（如 `role_parser.py`）
2. 在 `src/storage/` 下新增存储类（或复用现有）
3. 在 `scripts/` 下新增入口脚本 `crawl_xxx.py`
4. 在 `tests/` 下新增对应测试文件 `test_xxx_parser.py`
5. 调试脚本放在 `scripts/debug/` 下

### 7.2 复用组件

- `MediaWikiClient` — 所有爬取共用
- `load_config()` — 所有配置加载共用
- `setup_logging()` — 所有日志初始化共用
