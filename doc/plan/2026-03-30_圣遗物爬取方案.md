# 圣遗物爬取方案

> 本文档版本：v1.0（2026-03-30）

---

## 1. 概述

### 1.1 数据目标

爬取哔哩哔哩原神 Wiki 的圣遗物数据，用于 RAG/Agent 训练数据集。

**目标页面：**
- 圣遗物图鉴列表：https://wiki.biligame.com/ys/%E5%9C%A3%E9%81%97%E7%89%A9%E5%9B%BE%E9%89%B4
- 每套圣遗物的详情页：如 https://wiki.biligame.com/ys/%E5%A6%82%E9%9B%B7%E7%9A%84%E7%9B%9B%E6%80%92

### 1.2 爬取策略

采用 **HTML 解析** 方式，通过 MediaWiki API 的 `action=parse` 获取渲染后的 HTML，再用 BeautifulSoup 解析。

**原因：** 圣遗物详情页包含丰富的样式信息（如星级图片、套装效果表格），纯 wikitext 无法直接获取这些格式化数据。

## 3. 数据模型

### ArtifactInfo 字段

| 字段 | 类型 | 说明 |
|------|------|------|
| 套装名称 | str | 圣遗物套装名称 |
| 稀有度 | str | 如"4-5星"，通过星级图片 alt 确定范围 |
| TAG | str | 如"伤害、后台触发、月曜" |
| 实装版本 | str | 如"月之四" |
| 2件套效果 | str | 2件套加成效果 |
| 4件套效果 | str | 4件套加成效果 |
| 部件列表 | list | 5件部件的列表（ArtifactPiece） |
| 获取途径 | str | 获取途径文本 |
| 故事 | str | 5件套各自的 lore 文本 |

### ArtifactPiece 字段

| 字段 | 类型 | 说明 |
|------|------|------|
| 名称 | str | 部件名称（如"献与月的华梦"） |
| 类型 | str | 部件类型（生之花/死之羽/时之沙/空之杯/理之冠） |
| 描述 | str | 部件描述（如"生命值+4781"） |

## 4. HTML 结构解析（基于 `晨星与月的晓歌` 样本）

### 4.1 套装名称

```html
<div class="name">晨星与月的晓歌</div>
```

### 4.2 稀有度

```html
<div class="star">
<img alt="圣遗物套装-4星.png"...>&nbsp;&nbsp;~&nbsp;&nbsp;<img alt="圣遗物套装-5星.png"...>
</div>
```
通过 `img alt` 属性中的数字确定星级范围。

### 4.3 TAG 和实装版本

```html
<div class="tag"><b>TAG：</b>伤害、后台触发、月曜</div>
<div class="tag" style="margin:0"><b>实装版本：</b>月之四</div>
```

### 4.4 套装效果

```html
<table class="effect">
<tr><td>2件套</td><td>元素精通提高80点。</td></tr>
<tr><td>4件套</td><td>装备者处于队伍后台时...</td></tr>
</table>
```

### 4.5 圣遗物部件

```html
<div class="icon">
<div class="autoimg"><img alt="晨星与月的晓歌生之花.png"...></div>
<div class="main"><div class="up">献与月的华梦</div><div class="down">生之花</div></div>
</div>
```

### 4.6 获取途径

```html
<div class="get">
<div class="title">获取方式</div>
<div class="item">
<div class="access">
<div class="head">...</div>
<div class="mid"></div>
<div class="title">副本</div>
<div class="content">（4星）：祝圣秘境：月童的库藏 Ⅰ至Ⅳ概率掉落。</div>
</div>
</div>
</div>
```

### 4.7 圣遗物故事（lore）

```html
<div class="relic">
<div class="resp-tabs-container">
<div class="resp-tab-content" style="display: none;">
<div class="story">曾经有一个时代...<br/>
<p>那时，高天所降下的律法...</p>
</div><br/><br/>
<div class="item">古时为空月女神塑像的工匠...</div>
</div>
...
</div>
```

**换行规则：**
- 单个 `<br />` → `\n`
- 连续 `<br /><br />` → `\n\n`

## 7. 技术细节

### 7.1 请求配置

- 间隔：3 秒（`configs/config.yaml` 中 `request_interval`）
- 超时：30 秒
- 重试：最多 3 次，指数退避

### 7.2 错误处理

- 捕获具体异常类型，不使用裸 `except:`
- 失败圣遗物记录到 `failed_artifacts.txt`
- 支持断点续爬（读取已保存/失败记录后跳过）

### 7.3 日志

使用标准库 `logging`，格式：`%(asctime)s - %(name)s - %(levelname)s - %(message)s`
