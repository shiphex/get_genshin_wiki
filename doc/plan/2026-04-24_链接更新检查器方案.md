# 链接更新检查器方案

## 背景

原神 Wiki（wiki.biligame.com/ys/）会定期添加新内容（武器、书籍、圣遗物）。目前存储在 `tests/output/` 中的链接列表在初始爬取后会变得过时。本方案实现一个链接更新检查器。

## 需求

1. 获取 Wiki 中最新的数据链接列表，与本地对比
2. 可通过命令行检查链接列表是否更新
3. 如果有更新的链接，更新本地链接列表
4. 如果有删除的链接，询问用户是否删除
5. 更新后补充新数据
6. 补充数据后测试确保正确性完整性
7. 其他数据链接列表获取代码也按上述更新
8. 更新相关 `doc/plan/` 和 `doc/operation_guide/` 下的文档

## 实现内容

### 已创建文件

| 文件 | 说明 |
|------|------|
| `src/linkchecker/__init__.py` | 模块入口 |
| `src/linkchecker/models.py` | LinkItem、LinkList、ComparisonResult 数据类 |
| `src/linkchecker/comparator.py` | 基于集合的链接比较逻辑 |
| `src/linkchecker/checker.py` | LinkChecker 核心类 |
| `scripts/check_links.py` | CLI 入口点 |
| `tests/test_link_checker.py` | 18 个测试用例 |

### CLI 接口

```bash
python scripts/check_links.py --type arms --check-only
python scripts/check_links.py --type books --check-only
python scripts/check_links.py --type artifacts --check-only
python scripts/check_links.py --type arms --update --yes --crawl-new
```

- 书籍：102 链接
