# 武器数据爬取方案

> 本文档版本：v1.0（2026-03-28）

---

## 1. 概述

### 1.1 数据目标

- 武器图鉴列表（武器图鉴页面）
- 每件武器的详情页（如狼的武功歌等）
- 武器相关信息（名称、稀有度、性能描述、武器技能、突破材料等）

### 1.2 爬取策略

采用 **HTML 解析** 方式，通过 MediaWiki API 的 `action=parse` 获取渲染后的 HTML，再用 BeautifulSoup 解析。

## 2. 架构

### 2.1 已实现文件

| 文件 | 功能 |
|------|------|
| `src/parser/arms_parser.py` | 数据模型（Arm/ArmInfo dataclass）+ HTML 解析器 |

```

  ├── ArmsParser (src/parser/arms_parser.py)

```

## 4. 核心解析逻辑

### 4.1 武器发现

从"武器图鉴"页面 HTML 中提取所有武器链接：

```python
html = client.get_page_html("武器图鉴")
links = parser.extract_arm_links(html)
```

链接过滤规则（跳过非武器页面）：
- 排除 `/ys/文件:` 前缀（文件页面）
- 排除包含 `action=` 的链接
- 排除导航页面（角色一览、书籍一览等）

### 4.2 武器信息解析

**名称**：`<span class="mw-headline" id="狼的武功歌"><b>狼的武功歌</b></span>`

**稀有度**：`<div style="color:#FFAF52; font-size:x-large;">★★★★★</div>` 数 ★ 字符

**性能描述**：`攻击力 46-608 /// 暴击率 7.2%-33.1%`

**武器技能**：`>武器技能 - 不灭的骑士道</div>`

**技能描述**：技能名称后 `<div style="width:100%; margin-top:8px;">...</div>`

**突破材料**：`<div class="YSCard-BtnMatInfo"><img alt="凛风奔狼的始龀.png"/>`

## 6. 技术细节

### 6.1 请求配置

- 间隔：3 秒（`configs/config.yaml` 中 `request_interval`）
- 超时：30 秒
- 重试：最多 3 次，指数退避

### 6.2 错误处理

- 捕获具体异常类型，不使用裸 `except:`
- 失败武器记录到 `failed_arms.txt`
- 支持断点续爬（读取已保存/失败记录后跳过）

### 6.3 日志

使用标准库 `logging`，格式：`%(asctime)s - %(name)s - %(levelname)s - %(message)s`

- `load_config()` — 所有配置加载共用
- `setup_logging()` — 所有日志初始化共用

### 7.2 后续扩展

参考本方案的结构：

1. 在 `src/parser/` 下新增 `xxx_parser.py`（如 `role_parser.py`）

3. 在 `scripts/` 下新增入口脚本
4. 在 `tests/` 下新增对应测试文件
5. 调试脚本放在 `scripts/debug/` 下
