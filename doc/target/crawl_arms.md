# crawl_arms.md

本文件为武器爬取相关资料文档，包含武器爬取的目标、实际架构、组件关系和目录结构。

## 武器爬取目标
- 武器图鉴所在网页[武器图鉴](https://wiki.biligame.com/ys/%E6%AD%A6%E5%99%A8%E5%9B%BE%E9%89%B4)
- 武器列表所在网页[武器图鉴]中武器都属于`<div class="visible-xs">`类
- 每个武器的详情页，如[狼的武功歌](https://wiki.biligame.com/ys/%E7%8B%BC%E7%9A%84%E6%AD%A6%E5%8A%9F%E6%AD%8C)，该网页链接可在'武器图鉴'网页中找到
- 获取武器的相关信息：
  - 名称
  - 稀有度
  - 性能描述文本
  - 武器技能
  - 武器技能文本描述
  - 武器介绍
  - 实装版本
  - 获取途径
  - 武器类型
  - 武器TAG
  - 突破材料
  - 故事

## 部分信息获取方式
以武器`狼的武功歌`为例，获取其相关信息的网页代码如下：
- 名称、稀有度：  
  存在网页代码如`<span class="mw-headline" id="狼的武功歌"><b>狼的武功歌</b></span></h2> <div style="color:#FFAF52; font-size:x-large;">★★★★★</div>`中，可获得武器名称：`狼的武功歌`，武器稀有度依靠`★`字符识别，有几个`★`为几星稀有度
- 性能描述文本：
  文本存在于名称、稀有度网页代码下方如`<p>攻击力 46-608 <span class="visible-xs-inline"><br /></span><span class="hidden-xs">///</span> 暴击率 7.2%-33.1%`中，可获得武器的性能描述文本：`攻击力 46-608 暴击率 7.2%-33.1%`
- 武器技能
  文本存在于性能描述文本下方如`</div><div class="card-title2" style="width:100%; margin-top:16px;">武器技能 - 不灭的骑士道</div>`中，可获得武器的技能：`不灭的骑士道`
- 武器技能文本描述
  文本位于武器技能网页代码下方如`<div style="width:100%; margin-top:8px;">攻击速度提升10%。普通攻击命中敌人/施放元素战技/开始重击时，装备者将分别获得1/2/2层「四风诗系」：造成的伤害提升<span style="color:rgb(69 113 236)">7.5%/9.5%/11.5%/13.5%/15.5%</span>，该效果持续4秒，至多叠加4次，每0.01秒至多触发一次。此外，队伍拥有「魔导·秘仪」效果时，每层「四风诗系」还会使装备者的暴击伤害提高<span style="color:rgb(69 113 236)">7.5%/9.5%/11.5%/13.5%/15.5%</span>。</div>`中，可解析出武器技能文本描述：`攻击速度提升10%。普通攻击命中敌人/施放元素战技/开始重击时，装备者将分别获得1/2/2层「四风诗系」：造成的伤害提升7.5%/9.5%/11.5%/13.5%/15.5%，该效果持续4秒，至多叠加4次，每0.01秒至多触发一次。此外，队伍拥有「魔导·秘仪」效果时，每层「四风诗系」还会使装备者的暴击伤害提高7.5%/9.5%/11.5%/13.5%/15.5%。`
- 突破材料
  文本位于网页代码如`<div class="YSCard-BtnMatInfo"><img alt="凛风奔狼的始龀.png"`中，可提取出武器的突破材料：`凛风奔狼的始龀`。不同等级的突破材料会出现相同的情况，如果相同请不要重复列举。在列举的时候，将每个等级中列出的第一个突破材料靠近放置，然后是第二个，第三个

- 武器介绍
  文本位于
  ``` html
  <div class="card-title3">武器介绍</div>
  <div class="card-content3">传说中，是继承了「北风」之名的瑞文伍德，在成为骑士前亲手所铸的大剑。</div>
  ```
  可获得武器的介绍：`传说中，是继承了「北风」之名的瑞文伍德，在成为骑士前亲手所铸的大剑。`
- 获取途径
  文本位于网页代码如
  ``` html
  <div class="card-title3">获取途径</div>
  <div class="card-content3">限定祈愿</div>
  ```
  可获得武器的获取途径：`限定祈愿`
- 实装版本
  文本位于网页代码如
  ``` html
  <div class="card-title3">实装版本</div>
  <div class="card-content3">月之五</div>
  ```
  可获得武器的实装版本：`月之五`
- 武器类型
  文本位于网页代码如
  ``` html
  <div class="card-title3">武器类型</div>
  <div class="card-content3">双手剑</div>
  ```
  可获得武器的类型：`双手剑`
- 武器TAG
  文本位于网页代码如
  ``` html
  <div class="card-title3">武器TAG</div>
  <div class="card-content3">暴击伤害、伤害加成</div>
  ```
  可获得武器的TAG：`暴击伤害、伤害加成`  
- 故事
  文本位于网页代码如
  ``` html
  <div id="mc_collapse-1" class="panel-body panel-collapse collapse" style="height: 30px;  ">在诗与酒的国度，自古便流传着诸多歌咏骑士武功的篇章。<br />
  <p>在所有华美的诗篇当中，有关「狼」的故事往往最受欢迎。<br />
  毕竟相比威严的「狮」，自由的「狼」总是更合诗人胃口。<br /><br />
  故事的开头通常是这样的：<br />
  浮浪的骑士自北地而来，与名为北风的旅伴一同造访新获自由的城邦。<br />
  不羁的狼与骑士共猎，斩杀侵扰乡间的恶兽，又击退袭击海岸的巨蛇。<br />
  直到怀乡的孤狼将灵魂留在苍翠的郊野，骑士也追随着北风悄然离去。<br />
  最后也无人知晓游侠骑士的名姓，但他的声名却并未如愿被历史遗忘。<br /><br />
  浪漫的诗人们望文生义，在他们的笔下，无名骑士总在痛饮雪国的烈酒后步入战场。<br />
  但却鲜少有人知道，骑士到来是为了见证狼的命运，他的故乡也并不在无情的雪国。<br />
  毕竟在成为故事的主人前，故事外的骑士总是随性而行，完全没有作为英雄的架子。<br />
  除了坚持不懈想要将他收揽入麾下的大团长，酒馆的客人们只当他是个普通的酒客。<br /><br />
  唯一的例外是个名为瑞文伍德的少年，他是城中铁匠的儿子，<br />
  在无名骑士停留蒙德的短短数年里，少年几乎成了他的跟班。<br />
  相识的契机是在骑士初到蒙德时，曾委托他的父亲为其铸剑，<br />
  本应作为报酬，骑士携带的钱币上却压铸着无人能识的印记。<br />
  原本只为贵族铸剑的铁匠，索性将那柄厚重的铁片赠予了他，<br />
  「在新生的蒙德，所有人都应该拿起武器捍卫我们的自由。」<br /><br />
  后来，铁匠的儿子总是跟在无名骑士的身后，大多数时候只是静静地看着他练剑。<br />
  偶尔在精疲力竭时，夕阳下的骑士会自顾自地讲起，某个已被遗忘的异乡的故事。<br />
  那里遍布着永不凋谢的花朵，在流淌蜜酒的河畔有一个早已不复存在的勇士之国。<br />
  一度为贞情而高歌的勇士，在权力与金帛的诱惑前屈膝，甘愿为贪婪的暴君效力。<br />
  于是律法因此废坏，崇高的武德亦因之倾颓，直到奴役他人者最终也沦为了奴隶。<br />
  夜风吹起无名骑士破旧的斗篷，精雕着繁复花纹的甲胄在月光的照映下熠熠生辉。<br />
  放浪与自由是失乡的骑士最后的宿命，因为在这月下已不再有值得他守护的家园。<br /><br />
  许多年以后，「北风」的故事成为了传说，砸碎镣铐的英雄也离去了。<br />
  有言道艰苦卓绝的牺牲带来了自由，随之而来的安乐却往往通向奴役。<br />
  骑士团的诫命音犹在耳，昔日的战友却已背弃誓言投向旧贵族的怀抱。<br />
  在这样动荡不安的时局中，铁匠的儿子提起了新铸的长剑，走向荒野。<br />
  「自由与为自由而牺牲的勇气皆不可复生，珍惜你们高贵的美德吧。」<br /><br />
  几天之后，一位披着残破斗篷的骑士出现在了城塞的门外。<br />
  面对敌人他舞动起令人望而生畏的重剑，好似有魔神相助。<br />
  有老人认了出来，那是曾自称「北风」的骑士所用的剑技。<br />
  「是『北风』，是『北风』回来了！」<br />
  在人群的欢呼中，瑞文伍德阖上双眼…<br />
  </p>
  冲锋吧！为自由，为了不灭的骑士道！</div>
  </div>
  </div>
  </div>
  </div>
  ```
  该代码段所有文本均为故事文本，需要换行、分段按网页显示的效果保存，其中每个`<br />`都是一个换行符，每个`<br />`都使用一个换行符`\n`代替：
  - 不连续单个`<br />`只使用一个换行符`\n`代替
  - 连续的两个如`<br /><br />`使用两个如`\n\n`代替
  - 依次类推
