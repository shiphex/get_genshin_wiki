# 版本说明 - V2.2.0

本版本基于 `release/V2.1.0`，新增冻结来源离线恢复，并修复同名任务覆盖、剧情容器遗漏及分支归属丢失。Python 项目与锁文件中的版本统一为 `2.2.0`；第三方依赖版本保持不变。

## 新功能

- 从已保存的 WikiText 快照完全离线恢复对白、选项、旁白、角色故事、语音、书籍及描述，输出新的派生目录。
- 每个已恢复单元保存真实原页、原文位置、稳定 ID、场景、选择分支和缓存消费上下文，支持回查与确定性重放。
- 独立枚举原文候选节点，记录已导出、元信息、明确非剧情、缺来源及尚未支持的内容，保留未知节点和规则。

## 改进与修复

- 四个幕间小憩以完整原标题与页面 ID 分开保存，不再因展示名相同而互相覆盖；聚合、resume、排序和索引引用同步修正。
- 恢复剧情容器中的实际正文、空段落，以及颜色、注音、明确显示标签和折叠包装中的可见文字。
- 选项、tabber 和嵌套条件在展平前保存归属，重复台词与重名场景使用实际位置，不补写说话者或缺失剧情。
- 缓存引用先处理 onlyinclude / noinclude 可见性，再提取正文；文档示例不会作为剧情，重复消费保留全部场景和分支上下文。
- 覆盖统计只采用真正可见的文字来源，未知显示参数和折叠参数继续保留，避免将未渲染内容误计为已恢复。
- 修复原 CLI 测试的导入语法错误；冻结回归 payload 保留原始字节，防止 Git 换行转换破坏哈希验证。
- README、操作指南、架构及角色任务说明同步到当前入口、页面身份与来源契约。

## 验证结果

- 完整测试基线：122 passed / 18 subtests passed，包含 19 份真实冻结页面及字面位置锚点。
- 已完成的冻结实验处理 5,946 页，导出 172,136 个文本单元；原文重放无失败，29,918 条已知分支范围检查无失败。
- 同一输入两次运行的 5,952 个输出文件逐字节一致；11,439 个输入文件哈希不变。
- 本轮仅更新文档和版本元数据，不重新运行全量恢复；详细实验数据和 SHA-256 见[冻结恢复报告](../reports/snapshot_recovery_2026-10-10.md)。

## 升级与兼容性

- 角色任务保留“任务名称”作为展示名，增加 `source_title`、`page_id`；存储键、组索引中的 `tasks` 及结构化 `task_refs` 使用完整原页身份。
- 旧展示名文件名不能作为新结果查找键。缺少来源身份的旧汇总需从原页重新解析，不按展示名自动合并或跳过；保留旧输出，并把新结果写入独立目录。
- 旧业务对话数组继续作为兼容投影。新恢复的权威来源与分支以文本单元为准，下游按来源、场景、分支及消费上下文切分。
- 在线 `all` 与单页操作入口继续保留。离线恢复前需准备依赖，恢复期间禁止联网补抓、下载媒体或调用模型补写。

## 已知限制与发布内容

- 未识别模板、未支持正文别名、未缓存引用与媒体文字仍有缺口，150 个单元的分支归属尚未解决。
- 候选节点恢复比例 51.34%、中文字符恢复比例 64.72% 是保守实验指标，分母包括未裁定的 Wiki 内容，不代表剧情或全游戏覆盖率。
- 本次 GitHub Release 提供代码、测试和说明及 GitHub 自动生成的源码归档，不上传恢复数据，也不重新上传历史原始快照。
- 恢复数据保留在本地；现有 RAG 不自动切换，接入需独立验收。操作说明见[统一指南](../guide/unified_operation_guide.md)与[离线恢复指南](../guide/snapshot_recovery_guide.md)。
