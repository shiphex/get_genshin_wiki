## 1. 环境准备

### 1.1 进入虚拟环境

```bash
# Windows
.get_wiki\Scripts\activate

# Linux/Mac
source .get_wiki/Scripts/activate
```

### 1.2 安装依赖

```bash
uv pip install -e ".[dev]"
```

### 1.3 配置文件

主要配置文件位于 `configs/config.yaml`：

```yaml
mediawiki:
  api_url: "https://wiki.biligame.com/ys/api.php"  # MediaWiki API 地址
  base_url: "https://wiki.biligame.com/ys/"         # Wiki 基础地址
  request_interval: 3                                # 请求间隔（秒）
  timeout: 30                                        # 请求超时（秒）
  max_retries: 3                                      # 最大重试次数
  user_agent: "get_wiki_genshin/0.1.0 (...)"

storage:
  output_dir: "storage"
  book_dir: "storage/book"                           # 书籍数据输出目录
```

## 2. 执行命令

### 2.1 完整爬取（推荐）

爬取所有书籍数据，包含断点续爬功能（已爬取的书籍不会重复爬取）：

```bash
python scripts/crawl_books.py
```

**输出**：
- `storage/book/books.jsonl` — 结构化书籍数据（JSONL 格式，每行一条）
- `storage/book/raw/` — （预留，暂未使用）
- `storage/book/cleaned/` — 清洗后的纯文本（每本书一个 .txt 文件）
- `storage/book/failed_books.txt` — 爬取失败的书籍记录

### 2.2 测试书籍列表提取

仅提取书籍列表，不爬取详情页：

```bash
python scripts/debug/test_book_list.py
```

输出示例：
```
找到 102 本书籍:
  - 终北祷歌集: https://wiki.biligame.com/ys/终北祷歌集
  - 海螺的回响: https://wiki.biligame.com/ys/海螺的回响
  ...
```

### 2.3 测试单本书籍爬取

爬取指定书籍的详情页并保存测试结果：

```bash
python scripts/debug/test_single_book_save.py
```

默认测试书籍：终北祷歌集

### 2.4 保存书籍列表页 HTML

将书籍一览页面的原始 HTML 保存到项目根目录（用于调试）：

```bash
python scripts/debug/save_book_list.py
```

输出：`test_book_list.html`、`test_book_links.json`

## 3. 输出文件说明

### 3.1 books.jsonl 结构

每行一条 JSON 记录，字段说明：

| 字段 | 类型 | 说明 |
|------|------|------|
| `title` | string | 书籍标题 |
| `url` | string | 书籍页面 URL |
| `fetched_at` | string | 爬取时间（ISO 格式） |
| `info.名称` | string | 书籍名称 |
| `info.卷数` | string | 如"共3卷" |
| `info.稀有度` | string | 如"4星" |
| `info.体裁` | string | 如"诗歌" |
| `info.国家` | string | 如"挪德卡莱" |
| `info.实装版本` | string | 如"月之一" |
| `info.图鉴` | string | 如"是" |
| `info.相关角色` | list | 相关角色名称列表 |
| `info.获取方式` | string | 汇总格式："卷名1: 获取方式1; 卷名2: 获取方式2; ..." |
| `volumes` | list | 各卷内容数组 |
| `volumes[].title` | string | 卷标题 |
| `volumes[].content` | string | 卷文本（`<br />` 保留为 `\n` 换行） |
| `volumes[].obtain_method` | string | 该卷获取方式 |

### 3.2 cleaned/*.txt 结构

每本书一个纯文本文件，格式：

```
# 书籍名称

获取方式：卷名1: 获取方式1; 卷名2: 获取方式2; ...

## 章节

### 卷标题1

卷内容...

### 卷标题2

卷内容...
```

## 4. 常见问题处理

### 4.1 爬取失败

检查 `storage/book/failed_books.txt`，失败记录格式为：`书籍名\t失败原因`

重新爬取失败书籍：删除 `failed_books.txt` 中的对应行，或清空文件后重新运行 `crawl_books.py`

### 4.2 请求超时

默认超时 30 秒，最大重试 3 次，使用指数退避策略。若持续超时，可能是网络问题或 Wiki 服务器限速，建议等待后重试。

### 4.3 数据不完整

如果某本书缺少卷内容，可能是页面 HTML 结构变化。检查 `scripts/debug/test_single_book_save.py` 输出，或查看 `tests/output/` 下的临时文件进行调试。

### 4.4 清理数据

删除所有已爬取数据（慎用）：

```bash
rm storage/book/books.jsonl
rm storage/book/failed_books.txt
rm storage/book/cleaned/*.txt
```
