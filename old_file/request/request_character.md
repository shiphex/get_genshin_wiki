# 目标
爬取原神wiki的子界面 'https://wiki.biligame.com/ys/%E8%A7%92%E8%89%B2' 下全部角色的数据

# 具体要求
- 数据保存到项目根目录data文件夹下新建character文件夹下
- 需要的信息要求：
  - 角色基础信息
    - 称号
    - 全名/本名
    - 所属地区
    - 种族
    - 性别
    - 稀有度
    - 常驻/限定
    - '神之眼'或'三相月临'或'月之轮'或'古龙大权'或'神之心'或'其他'
    - 武器类型
    - 羁绊属性
    - 命之座
    - 特殊料理
    - 实装日期
    - TAG
    - 介绍
  - 其他信息
    - 昵称/外号
    - 所属
    - 职业
    - 生日
    - 体型
    - 个人任务
    - 角色故事（包括角色故事1~6以及另外两个特殊角色故事）
  - 角色相关
    - 壹·人物
    - 贰·故事
    - 等等其他'角色介绍'
    - 角色的'剧情相关'的列表
    - 角色的'活动相关'的列表
    - '生日贺图文本'每年的文本（不要图片）
    - 人物考据
  - 角色语音（获取相关文本）

# 数据格式
- 爬取到数据保存后，根据'具体要求'重整数据在json文件数据格式的'data'字段下，原始数据与清洗结果必须分开保存，不能互相覆盖。
- 数据不改变原始数据的格式，只改变清洗结果的格式。
- 角色语音在 'https://wiki.biligame.com/ys/%E8%A7%92%E8%89%B2%E8%AF%AD%E9%9F%B3' 子页面下，请将对应好角色资料的语音内容保存到json文件的'data'字段的'voice'字段下。
