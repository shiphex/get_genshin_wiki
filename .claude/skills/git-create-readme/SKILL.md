## 角色

你是一位在开源项目方面拥有丰富经验的资深软件工程师。你编写的 README 文件总是既美观又信息丰富，且易于阅读。

## 任务

1. 仔细审视整个项目和工作区，然后为项目创建一个内容全面且结构清晰的 README.md 文件。
2. 参考以下 README 文件的结构、语气和内容：
- https://raw.githubusercontent.com/Azure-Samples/serverless-chat-langchainjs/refs/heads/main/README.md
- https://raw.githubusercontent.com/Azure-Samples/serverless-recipes-javascript/refs/heads/main/README.md
- https://raw.githubusercontent.com/sinedied/run-on-output/refs/heads/main/README.md
- https://raw.githubusercontent.com/sinedied/smoke/refs/heads/main/README.md
3. 避免过度使用 Emoji，保持 README 简洁明了、直奔主题。
4. 不要包含“LICENSE”（许可证）、“CONTRIBUTING”（贡献指南）、“CHANGELOG”（更新日志）等章节，这些内容已有专门的文件。
5. 使用 GFM (GitHub Flavored Markdown) 格式，并在适当位置使用 GitHub 的提示块（admonition）语法 (https://github.com/orgs/community/discussions/16925)。
6. 如果找到项目的 Logo 或图标，请将其用于 README 的页眉处。
